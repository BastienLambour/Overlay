Moodboard de l'overlay néon. Tout ce qui est affiché ci-dessous est la vraie page utilisée dans OBS, en mode test. Change la couleur en haut : cadres, textes et éclats du fond suivent partout.

Les couleurs

Une seule couleur d'accent sur une base noire et grise. Vert par défaut, les autres prêtes pour les jeux où elles rendent mieux. Dans OBS : couleur dans config.js, ou ?couleur=rouge sur une seule scène.

Le fond cristal

Le fond est généré : facettes nettes, éclats dans la couleur d'accent qui respirent très doucement (désactivable). Les cadres ont un trait régulier, un fin liseré sombre et un halo discret. Version transparente pour la cam et le jeu, version « verre » fumée pour le chat.

Les composants

Le chat reprend ton format en cartes : pseudo dans sa couleur Twitch, badges (streamer, modo, VIP, abonné…), emotes. Les alertes restent sobres : une carte qui apparaît en fondu avec un petit carillon ; les gros événements (raid, pluie d'abonnements, objectif) font pulser le halo.
